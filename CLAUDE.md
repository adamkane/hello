# hello

Super simple Hello World React app deployed at hello.forgefx.dev.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS

## Dev Commands

```bash
pnpm install    # Install dependencies
pnpm run dev    # Dev server (port 4100)
pnpm run build  # Production build
```

## Deployment

- **URL**: https://hello.forgefx.dev
- **Vercel**: Deployed via adamkane/hello repo
